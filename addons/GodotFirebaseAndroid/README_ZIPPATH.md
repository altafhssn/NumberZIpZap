# ZipPath Firebase Android bridge

This is a scoped build of the MIT-licensed GodotFirebaseAndroid v1.0 plugin.
It contains only Firebase Authentication and Cloud Firestore support.

ZipPath updates the bridge to Godot 4.6.2, Firebase Android BoM 34.15.0,
Firebase Auth 24.1.0, Firestore 26.4.0, and Android Credential Manager Google
Sign-In. The upstream license is preserved in `LICENSE`.
